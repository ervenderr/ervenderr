## About me

I am a software engineer who ships end to end: Next.js and React on the front, FastAPI, Node and PostgreSQL on the back, and an AI layer on top that is built to be tested, not just demoed.

- 🧠 **AI engineering:** LLM agents with tool use, RAG, workflow automation (n8n), and evals with published pass rates
- 🛡️ **Reliability first:** I follow a "the model proposes, the code decides" rule, so validation, booking, auth and escalation logic stay in plain code
- 🏢 **Day job:** Software / AI Engineer at Appstango, building client systems and AI automation
- 🎓 BS in Computer Science, Western Mindanao State University (2024)
